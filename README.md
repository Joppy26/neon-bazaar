Neon Bazaar — a three.js tactical FPS set in a rain-soaked neon night market: round-based 5v5 against bots, two bomb sites, a buy economy between rounds, and a power round every third round with a prototype railgun up for grabs.

## Run it

```sh
node serve.ts 8080
```

Then open http://localhost:8080/ in desktop Chrome.
